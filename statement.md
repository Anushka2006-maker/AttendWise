# Project Statement

## Problem Statement
Keeping attendance records manually can make it difficult to find attendance shortages, maintain consistent records, and identify students who may need attention. AttendWise provides a small command-line system for organising these tasks.

## Scope
The application manages student details, records attendance sessions, calculates attendance percentages, classifies attendance risk, and creates text reports. It is intended as an academic demonstration project rather than a replacement for an institutional attendance system.

## Target Users
- Faculty members
- Class coordinators
- Academic administrators

## High-Level Features
- Student CRUD operations
- Attendance recording
- Duplicate attendance prevention
- Attendance percentage calculation
- Risk classification
- Attendance report generation
- File-based data persistence
